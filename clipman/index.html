Clipman

Accessible clipboard history that stays useful: fast to search, comfortable with a keyboard or screen reader, private by default, and available across desktop and mobile.

Windows, macOS, Linux, Android, iPhone and iPad

A clipboard history built for daily use

Clipman keeps ordinary copy and paste simple, then adds the organisation and cross-device tools that become useful when clipboard history is part of your working day.

Designed for accessibility

Controls expose meaningful names, roles, states and values. History supports concise screen-reader speech, predictable keyboard movement, search and type-to-jump navigation.

More than plain text

Keep text, named links, rich text and images organised in focused views. Desktop file history remembers copied files without sending machine-specific paths to other devices.

Local by default

No account is required. History can remain entirely on one device, and Clipman contains no advertising, developer analytics or third-party tracking.

Encrypted sync when you want it

An optional self-hosted Clipman Server can merge history across platforms. Encryption happens on your devices; the server stores the database but cannot read its contents.

Fast retrieval

Pin, name, edit, group, filter and reorder important entries. Quick Paste and templates put frequently used content into the active application without a trip through history.

Practical privacy controls

Ignore selected applications, exclude likely sensitive values, encrypt history, or keep short private snippets in machine-local Secrets instead of shared history.

Start in a minute

  1. Install the build for your platform and open Clipman.
  2. Copy a few pieces of text, then open history using the shortcut shown in the app or its menu.
  3. Choose an entry to return it to the clipboard. That is enough for ordinary local use.

Settings cover optional views, sounds, encryption, automatic paste, backups and synchronization. The complete manual documents every platform and command.
